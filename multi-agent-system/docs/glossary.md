## General Terms

| Term | Plain-English Explanation |
|------|--------------------------|
| **Agent** | A piece of software that uses an AI to make decisions and take actions toward a goal. Think of it like an employee who thinks for themselves. |
| **API** | Application Programming Interface — a way for two programs to talk to each other. When this system calls Groq, it is using an API. |
| **API Key** | A secret password that gives you access to an API service like Groq or Tavily. Keep it private. |
| **CLI** | Command-Line Interface — a text-based way to interact with a program (as opposed to clicking buttons in a window). |
| **Checkpoint** | A saved snapshot of the pipeline's state at a specific moment in time. Allows the pipeline to pause and resume. |
| **Conda / venv** | Tools for creating isolated Python environments so your project's packages don't conflict with others. |
| **HTTPS** | Secure internet communication protocol — all external API calls use this. |
| **Library / Package** | Pre-written Python code that you can install and use. Example: `fastapi`, `rich`. |
| **Markdown** | A simple text formatting language. Add `**` around text to bold it, `#` to make a heading, etc. |
| **pip** | Python's package installer. `pip install fastapi` downloads and installs the FastAPI library. |
| **Python** | The programming language this entire project is written in. |
| **Sandbox** | A restricted area where code can run or write files without affecting anything outside. This system's sandbox is `output/generated_code/`. |
| **Terminal** | Another word for the command-line window (also called "shell", "console", or "prompt"). |
| **TypedDict** | A Python feature that lets you define exactly what keys and types a dictionary must have. Used for `AgentState`. |
| **YAML / JSON** | Common file formats for storing structured data. Not heavily used in this project, but common in configuration files. |

## AI / LLM Terms

| Term | Plain-English Explanation |
|------|--------------------------|
| **LLM** | Large Language Model — the AI brain behind this system. Groq's `llama-3.3-70b-versatile` is an LLM. |
| **Groq** | A company that provides very fast LLM inference (much faster than OpenAI or Anthropic). The system uses their API. |
| **Llama** | An open-source LLM family created by Meta (Facebook's parent company). This project uses `llama-3.3-70b-versatile`. |
| **LangChain** | A Python framework that makes it easier to build applications with LLMs. Provides `@tool`, `BaseMessage`, etc. |
| **LangGraph** | An extension of LangChain for building agent workflows as graphs (connected boxes). The orchestrator uses this. |
| **MOCK mode** | When the system runs without making real LLM calls. Uses pre-written example outputs. Useful for testing. |
| **Prompt** | The text you send to an LLM to ask it a question or give it a task. |
| **System prompt** | A hidden set of instructions at the start of every LLM conversation that sets the AI's "personality" and rules. |
| **Temperature** | A setting that controls how creative the LLM is. Low temperature (0.2) = more predictable. High (1.0) = more random. |
| **Token** | LLMs process text as "tokens" (roughly 3/4 of a word each). API pricing is usually per 1000 tokens. |
| **Inference** | The process of running an LLM to generate a response. "Fast inference" means getting answers quickly. |

## Project-Specific Terms

| Term | Plain-English Explanation |
|------|--------------------------|
| **AgentState** | The shared "whiteboard" (Python dictionary) that all agents read from and write to. Contains the task, guide, files, etc. |
| **await_guide** | A node in the LangGraph graph that pauses the pipeline for human review of the Research Guide. |
| **await_run** | A node that pauses before handing off to the Testing Agent. |
| **await_report** | A node that pauses for human review of the final QA report. |
| **Coding Agent** | Agent 2. Reads the research guide and builds the project (creates folders, installs packages, writes code). |
| **HITL** | Human In The Loop — a design pattern where a human is asked to approve or reject an AI's action before it runs. |
| **HITL Gate** | A specific pause point in the pipeline where the system shows you what it wants to do and waits for your APPROVE/REJECT/EDIT response. |
| **Implementation Guide** | A Markdown document generated by the Research Agent containing the project plan (overview, libraries, structure, steps). |
| **interrupt()** | A LangGraph function that genuinely pauses the graph and waits for a human decision before continuing. |
| **MemorySaver** | LangGraph's in-memory checkpointing system. Saves state after every node so the pipeline can pause and resume. |
| **Orchestrator** | The `graph/orchestrator.py` file that wires the three agents together and controls the pipeline flow. |
| **Research Agent** | Agent 1. Searches the web, talks to the LLM, and generates the Implementation Guide. |
| **Singleton** | A design pattern where only one instance of a class ever exists. `AgentUI` is a Singleton so all agents share the same dashboard. |
| **StateGraph** | A LangGraph concept — a directed graph where each node is a function (agent) and edges define which function runs next. |
| **step_log** | A list of strings in `AgentState` that records every significant action during the pipeline run. |
| **Testing Agent** | Agent 3. Reads the generated code, writes pytest tests, runs them, proposes auto-fixes, and writes the QA report. |
| **thread_id** | The unique identifier for a LangGraph pipeline run. Used by MemorySaver to save and find checkpoints. |

## HITL Decision Terms

| Term | Meaning |
|------|---------|
| **APPROVE** (or **A**) | Go ahead — execute the proposed action |
| **REJECT** (or **R**) | Do not execute — skip or stop the action |
| **EDIT** (or **E**) | I want to change it — show me an input prompt |
| **`---END---`** | The sentinel string you type to finish a multi-line EDIT |

## Python / Technical Terms

| Term | Plain-English Explanation |
|------|--------------------------|
| **`@tool`** | A Python decorator from LangChain that marks a function as a tool that AI agents can call. |
| **`async` / `await`** | Python keywords for writing non-blocking code. The pipeline uses these so it doesn't freeze while waiting for web requests. |
| **`asyncio`** | Python's built-in library for running async code. `asyncio.run(main())` starts the pipeline. |
| **`deepcopy`** | Creates a completely independent copy of a Python object. Used in agents to avoid accidentally modifying the original state. |
| **`Path`** | A Python class (from `pathlib`) for working with file paths in a cross-platform way. |
| **`subprocess`** | A Python module for running external programs from within Python code. Used to run `pip install` and `pytest`. |
| **`TypedDict`** | A Python type hint feature that defines what keys a dictionary must have and what types they are. |
| **`@dataclass`** | Not used here, but a common Python feature for defining simple data classes. |
| **regex** | Regular expressions — a powerful language for matching patterns in text. Used to parse the Implementation Guide. |
| **`PYTHONIOENCODING`** | An environment variable that tells Python what encoding to use for text output. Set to `utf-8` for best Unicode support on Windows. |

## File Format Terms

| Term | Explanation |
|------|-------------|
| **`.env`** | A text file containing environment variable definitions. Loaded by `python-dotenv`. |
| **`.gitignore`** | A file that tells Git which files to never track or commit. `.env` is listed here. |
| **`requirements.txt`** | A text file listing all Python packages needed for this project, one per line. |
| **Markdown (`.md`)** | A text format using `#` for headings, `**` for bold, `` ` `` for code, etc. GitHub renders it beautifully. |
| **ASCII art** | Text-based art made from keyboard characters. The welcome banner uses this. |
| **Mermaid** | A JavaScript library for rendering diagrams from text. Used in all the documentation. |
