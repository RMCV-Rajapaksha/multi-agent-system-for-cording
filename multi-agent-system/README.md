# Multi-Agent LangGraph System

This project is a multi-agent system built using [LangGraph](https://python.langchain.com/docs/langgraph/) and [LangChain](https://python.langchain.com/docs/get_started/introduction). It utilizes three specialized agents—**Research**, **Coding**, and **Testing**—to collaboratively accomplish complex tasks. The system features a shared state, a human-in-the-loop (HITL) approval mechanism, and a beautiful terminal user interface powered by [Rich](https://rich.readthedocs.io/).

## 📁 Project Structure

The project has the following directory layout:

```text
multi-agent-system/
├── agents/                 # Code for the individual agents (Research, Coding, Testing)
├── tools/                  # Custom tools that agents can use (e.g., web search, file write)
├── graph/                  # LangGraph definitions and state management
│   └── state.py            # Defines the shared `AgentState` TypedDict used by all agents
├── ui/                     # User interface components
│   └── terminal_ui.py      # The `AgentUI` class for rendering beautiful terminal output
├── output/
│   ├── generated_code/     # Destination for source code generated by the Coding agent
│   └── test_reports/       # Destination for test results generated by the Testing agent
├── .env.example            # Template for environment variables (API keys)
├── requirements.txt        # Python dependencies
├── setup.py                # Initialization script to build the structure and install packages
└── README.md               # This file
```

## ✨ Core Components

### 1. `setup.py`
A rich, interactive setup script that bootstraps the project. It:
- Creates the necessary folder structure with `.gitkeep` placeholders.
- Verifies the existence of `requirements.txt` and `.env.example`.
- **Human-in-the-Loop (HITL):** Prompts the user for approval before running `pip install`.
- Installs all necessary dependencies in the current environment.
- Displays a final success summary and folder tree.

### 2. `graph/state.py`
Defines the `AgentState` schema using Python's `TypedDict`. This state is the central nervous system of the LangGraph, flowing through every node (agent) in the pipeline. It tracks:
- **Conversation History:** `messages`
- **Agent Outputs:** `research_guide`, `folder_structure`, `generated_files`, `test_results`
- **Runtime Tracking:** `current_agent`, `terminal_output`, `error`
- **Human-in-the-Loop State:** `hitl_decision`, `hitl_edit_value`, `pending_approval`
- **Observability:** `step_log` (tracks reasoning and decisions)

### 3. `ui/terminal_ui.py`
Provides the `AgentUI` class for rendering a beautiful, Aqua-themed console interface using the `Rich` library. It abstracts away the styling logic, providing simple methods like:
- `show_step()`: Announces when an agent begins a task.
- `show_reasoning()`: Displays an agent's internal thought process.
- `show_tool_call()` & `show_result()`: Visualizes tool invocations and their outputs.
- `show_agent_transition()`: Animates the handoff between agents (e.g., RESEARCH ──────► CODING).
- `request_approval()`: Implements the **HITL gate**, pausing execution to ask the user for `APPROVE`, `REJECT`, or `EDIT` decisions with clear warning panels.
- `show_hitl_summary()`: Prints a table summarizing all human interventions during the run.

## 🚀 Getting Started

1. **Activate your environment** (Optional but recommended):
   ```powershell
   # Example for virtualenv
   .\venv\Scripts\Activate.ps1
   ```

2. **Run the Setup Script**:
   ```powershell
   python setup.py
   ```
   Follow the on-screen prompt to approve the package installation.

3. **Configure Environment Variables**:
   Copy the example file:
   ```powershell
   cp .env.example .env
   ```
   Open `.env` and add your API keys:
   - `GROQ_API_KEY`: Required for the LLM. Get it from [Groq Console](https://console.groq.com).
   - `TAVILY_API_KEY`: Optional, used if your research agent utilizes Tavily for search.
